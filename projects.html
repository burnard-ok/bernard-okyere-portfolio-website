An Efficient Computer Vision and Machine Learning Model for Real-Time Litter Detection on Raspberry Pi

Published by International Journal of Innovation and Development (IJID) · Dec. 06, 2023

PythonRaspberry PiTensorFlowSSD MobileNet V2 FPNLite

This project demonstrates the practical use of computer vision and machine learning to support waste management and environmental preservation. A convolutional neural network and computer-vision pipeline were designed and deployed on a Raspberry Pi for real-time litter detection, using the SSD MobileNet V2 FPNLite 320×320 model to improve the accurate identification of different litter types.
